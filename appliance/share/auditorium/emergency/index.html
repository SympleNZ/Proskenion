What to do

  1. Do not power-cycle repeatedly. One clean restart is reasonable; if this page returns, the storage needs attention.
  2. Connect over SSH from the management address and check the data partition: sudo journalctl -b -u data.mount and sudo smartctl -H /dev/nvme0n1.
  3. If the filesystem is damaged: sudo fsck.ext4 -f /dev/disk/by-partlabel/data with the partition unmounted, then reboot.
  4. If the SSD has failed: fit a replacement, write the golden image, and restore the most recent backup from the backup USB or the network destination.
  5. Follow docs/hardware/recovery.md for the full procedure. Exit from this mode is automatic: repair the storage, reboot, and the system starts normally.
