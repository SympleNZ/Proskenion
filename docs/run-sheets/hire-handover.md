> For: the staff member handing the hall to a hirer, and taking it back.

*Print this page and laminate it. Keep it by the rack.*

## Before a hire

- [ ] Change the hirer PIN
- [ ] Enable hirer access
- [ ] Confirm the permitted channels, desk scenes and lighting groups are
      right for this hire
- [ ] Recall the appropriate CQ desk scene as the baseline
- [ ] If an external lighting desk is in use:
  - [ ] Confirm it is patched into the booth DMX input — detection is
        automatic, nothing to switch on
  - [ ] Confirm the screen shows "under external control" and the panel
        indicator lights
  - [ ] Only turn on External Control by hand if the desk is **not** plugged
        into the booth input (bypassing it) — otherwise leave it alone
- [ ] Check the hirer screen loads on the touch-screen PC

## After a hire

- [ ] Disable hirer access
- [ ] Confirm the visiting desk is switched off — the controller takes back
      over by itself, 5 seconds later
- [ ] If External Control was turned on by hand, turn it off again
- [ ] Press "Restore Venue Default"
- [ ] Check phantom power matches the venue default (on MixPad — not visible
      from this screen)
- [ ] Check the matrix's audio output is still set to HDMI 1 (front panel of
      the matrix, in the rack)
- [ ] Run "Compare Baseline" and look into anything it flags as unexpected

---

**If the alarm/All Off is used while a visiting desk is connected:** it
cannot force the desk's own lighting to black — the desk's levels win over
the controller's. This is normal, not a fault. Switching the desk off is
what clears it, which is why it is on this list every time.

Running an event: the operator quick reference sheet. If the controller
itself is not responding: the recovery card.
